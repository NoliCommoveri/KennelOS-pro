Your license key can be activated on a limited number of devices. Release this one when you stop using it — before you clear this browser's data, hand the computer on, or switch to a new one — and its slot goes back so another device can use it. Your records are not touched and stay on this device; you can re-activate here any time with the same key.

Download a backup before you release. Afterwards Pro asks for a key on this device again, and that includes Import / Export — so export while you still can. You'll be offered the download when you confirm.
